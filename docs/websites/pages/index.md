## 模块概览

| 模块 | 覆盖 |
| --- | --- |
| 库存模块 | 二级库物资、库存余额与流水、补库与低库存、精简库存 |
| 申购模块 | 申购计划、请购与到货 |
| 采购跟踪 | 按申购单号整单同步外部平台 |
| 数据协同 | Excel 导入导出、链接分享 |
| 平台能力 | 图片附件、AI 搜索与 MCP、备忘录 |
| 用户与权限 | 四角色、微信身份合并、接口令牌 |

完整功能清单见 [功能总览](/features)；每项功能的接口、表结构与流程见[开发资料](/dev-overview)。
